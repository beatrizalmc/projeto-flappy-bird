# Flappy Bird Clone

Este é um clone do famoso jogo **Flappy Bird**, desenvolvido em HTML, CSS e JavaScript.
O projeto foi construído acompanhando um curso da Udemy [link](https://www.udemy.com/course/curso-web/learn/lecture/10285424), onde fui desenvolvendo junto com as aulas e entendendo cada parte da lógica do jogo. 

Além do que foi ensinado no curso, fiz algumas personalizações próprias:

- Alterações de cores e fontes para dar um estilo diferente.
- Adição de um botão de Restart, permitindo reiniciar o jogo sem precisar recarregar a página.

O objetivo foi adquirir aprendizados sobre a integração de HTML, CSS e JS.

---

## Funcionalidade

* Pássaro controlado pelas teclas do teclado (pressionar para voar e quando solta a tecla ele desce).
* Barreiras que se movimentam horizontalmente e mudam de altura aleatoriamente.
* Sistema de pontuação que aumenta conforme o jogador passa pelas barreiras.
* Detecção de colisão entre o pássaro e as barreiras.
* Game Over com opção de reiniciar pelo botão de Restart.

## Funcionalidades do Formulário

* Campos obrigatórios com validação HTML
* Upload de certidão de nascimento (PNG ou JPEG)
* Seleção de turno (manhã ou tarde)
* Escolha de atividade esportiva
* Aceite de termos e política de privacidade
* Layout dividido em formulário + capa institucional. Sendo que a capa é fixa, e o formulário rolável.

## Como Executar o Projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/beatrizalmc/projeto-flappy-bird
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd projeto-flappy-bird
   ```

3. Abra o arquivo `index.html` no navegador
